## Introduction

Ugarit MCP allows you to rapidly build MCP servers for your Ugarit applications. MCP servers allow AI clients to interact with your Ugarit application through the [Model Context Protocol](https://modelcontextprotocol.io/docs/getting-started/intro).

## Official Documentation

Documentation for Ugarit MCP can be found on the [Ugarit website](https://ugarit.com/docs/mcp).

## Contributing

Thank you for considering contributing to Ugarit MCP! The contribution guide can be found in the [Ugarit documentation](https://ugarit.com/docs/contributions).
